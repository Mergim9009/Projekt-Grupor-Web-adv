# Fitlife - Modern Fitness Website

Fitlife is a responsive fitness website built with HTML, CSS, and JavaScript. It features a clean, modern design with a black and red color scheme, and includes multiple pages for classes, blog posts, workout planning, and user authentication.

## 🚀 Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Workout Planner**: Create custom workout plans based on goals
- **Class Booking**: Browse and sign up for fitness classes
- **Blog Section**: Read fitness-related articles and tips
- **User Authentication**: Sign up and sign in functionality
- **Contact Form**: Easy way to get in touch

## 🛠️ Technologies Used

- **Frontend**:
  - HTML5
  - CSS3 (with CSS variables for theming)
  - JavaScript (ES6+)
  - [Ionicons](https://ionic.io/ionicons) for icons
  - [Google Fonts](https://fonts.google.com/) for typography

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, etc.)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Projekt-Grupor-Web-adv.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Projekt-Grupor-Web-adv
   ```
3. Open `index.html` in your web browser to view the website locally.

## 🎨 Customization

### Changing Colors
Modify the CSS variables in `assets/css/style.css` to change the color scheme:

```css
:root {
  --primary: #ff0336;      /* Main red color */
  --secondary: #1e1f29;    /* Dark background */
  --accent: #ffd700;       /* Accent color */
  --text: #ffffff;         /* Main text color */
  --text-secondary: #a1a1a1; /* Secondary text */
}
```

### Adding New Pages
1. Create a new HTML file (e.g., `about.html`)
2. Copy the basic structure from an existing page
3. Update the navigation links in the header
4. Add your content
